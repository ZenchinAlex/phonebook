# Phonebook CLI

Консольная записная книжка на Python. Хранит контакты в JSON-файле.

## Возможности
- Поиск контакта по имени
- Добавление контакта (проверка пустого ввода и дублей)
- Просмотр всех контактов с номерами
- Автоматическое сохранение в `contacts.json`

## Запуск
1. Установите Python 3.12
2. `git clone https://github.com/ZenchinAlex/phonebook.git`
3. `cd phonebook`
4. `python phonebook.py`

Файл `contacts.json` создастся автоматически при первом добавлении контакта.
